## Reader installation

Public SWORD package once the Pages publication succeeds:

https://icfmp.github.io/Bible-Resources/sword/packages/BRMHCC.zip

The ZIP contains a standard SWORD `mods.d/brmhcc.conf` and six
original compressed module files under
`modules/comments/zcom/brmhcc/`. Install through a reader's normal
SWORD ZIP import, or extract under the appropriate SWORD module root.

The source author's words, internal headings, introduction contents,
quoted Scripture, cross-reference targets and ordered native keys are
**not edited**. Only the module identifier, data path and curated
release `Version=0.1.0` differ from the CrossWire configuration.

## Textual and legal limits

CrossWire attributes its text to a Moody Press 28th printing and
an earlier digital transcription with subsequent corrections.
Bible Resources has preserved that **specific compiled digital
witness**; it does not certify letter-for-letter identity with a
printed copy. The separate CCEL ThML witness was *not* imported and
should not be assumed identical.

The original source's **Public Domain** declaration is maintained.
Only the independently authored Bible Resources English **reader
description** is made available under **CC0 1.0**, to the extent
the project owns rights in that description. The original compiled
CrossWire content is **not newly relicensed** by Bible Resources.
