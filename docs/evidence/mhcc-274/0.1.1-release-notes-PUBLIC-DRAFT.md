# DRAFT ONLY — Bible Resources BRMHCC 0.1.1

**Release notes proposed for editorial review. The release is NOT
published or approved.**

### What is improved?

This update to *Matthew Henry's Concise Commentary on the Whole Bible*
improves the native verse-address navigation of the original CrossWire
MHCC 2.0 digital commentary while preserving its original authorial
sections, paragraph divisions and theological exposition.

- **17 existing commentary sections / 24 added SWORD verse links.**
  Those addresses now lead to the original corresponding section
  rather than a missing navigation entry. No new exposition is created,
  unrelated sections are not merged and missing verses are not invented.
- **Ezekiel 3.** Corrected one demonstrably malformed citation and
  its internal reference target, `3:12–2` → `3:12–21`, in an original
  commentary source body linked from 11 existing native verse addresses.
- **1 Chronicles 7.** Corrected one demonstrable digital transcription
  typo, `Zebulun or Dn` → `Zebulun or Dan`, in one original commentary entry.

All other original numbered commentary entries, book/chapter
introductions, anonymous native records and existing section links
remain as in the source-attested rebuild. The two edits are explicitly
documented and reversible; this edition is therefore **not** claimed
to be byte-identical to the upstream CrossWire module.

### Source and compatibility

- Source: CrossWire `MHCC` 2.0, 2021-02-14;
  [official source record](
  https://crosswire.org/sword/modules/ModInfo.jsp?modName=MHCC).
- Curated SWORD module: `BRMHCC`, release version `0.1.1`,
  `zCom`, KJV versification, chapter-based compression.
- CrossWire's distribution declaration: `Public Domain — Copy Freely`.
  Bible Resources does not attempt to relicense the upstream digital
  text. The separate CCEL digitization is **not included**.
- Verification: entire original-to-rebuild SWORD K/I/TOP data corpus
  checked, all 24 new native links tested, representative passages read
  in Xiphos. Not a certification of every third-party reader's layout.

CrossWire's historical Moody Press edition description remains clearly
attributed to CrossWire and should not be treated as independently
verified print-edition identity.
