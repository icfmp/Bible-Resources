# Roadmap

1. Prove the pipeline with one legally redistributable Bible, commentary, and dictionary.
2. Import CrossWire resources selectively with original source archives and transformation logs.
3. Publish diagnostic reports for typography, duplicated scripture and malformed references.
4. Monitor distinct installed/curated/upstream versions for CrossWire and eBible (read-only checker and daily Actions report); implement user-consented verified client updates in Bible separately.
5. Implement a future API without replacing the existing SWORD distribution structure.
