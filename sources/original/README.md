# Immutable original sources

Only **real source files** under
`<category>/<language>/<resource-id>/`, accompanied by their exact
`PROVENANCE.json` records. Originals may be OSIS XML, USFM archive, or a
separately approved standards-based source. Do not modify the original to
remove whitespace, change Scripture, restore a verse, fix a link or improve
formatting. Edited masters must go under `../cleaned/` only after validation.

Types and actual original files in the repository:
- [French Bibles](bibles/fr/): Segond 1910 USFM and Darby 2024 OSIS.
- [English commentaries](commentaries/en/): MHC CrossWire original OSIS.

No fake empty dictionary/encyclopedia folders are created. If the exact
digital source rights are unclear, keep the bytes outside the public repository
and commit only legally permissible metadata.
