# MHC — legacy source-provenance entrypoint

**No cleaned full MHC OSIS body has been committed here.** The authoritative
historical source-provenance and cleanup documentation remains at
[`sources/cleaned/mhc/`](../../mhc/), in particular:

- [Original-source identity and exact OSIS hash](../../mhc/README.md)
- [Cleanup and review status](../../mhc/CLEANUP_STATUS.md)
- [Recorded historical changes](../../mhc/CHANGES.md)

We deliberately **did not move or copy** these three documents: the old
paths are referenced in source-bound historical evidence. A Git symlink
would preserve local filesystem navigation but would not preserve every
nested GitHub permalink.

This directory is a type-correct **index**, not a claim of a regenerated,
published editable OSIS edition. A future rights-cleared and fully
verified master should be placed under the typed structure and must retain
the source/edition hashes and the reversible cleanup report. Existing
published SWORD metadata: [MHC](../../../../modules/mhc-crosswire/metadata.json).
