# Source texts: originals and verified cleaned masters

This is the **actual source store**, grouped by **type / language / edition**,
not a place to keep placeholder folders or historical review notes.

```text
original/
  bibles/fr/lsg-1910/               original USFM ZIP
  bibles/fr/darby-jnd-2024/         original OSIS XML
  commentaries/en/mhc-crosswire/    original OSIS XML
cleaned/
  ...                               only real, independently reviewed
                                    OSIS/USFM masters when available
```

The original directories contain actual source bytes and
`PROVENANCE.json` records; no automatic cleanup has been applied to them.
No original source should be mistaken for an edition's completed *cleaned*
master, or for the published compiled SWORD module.
