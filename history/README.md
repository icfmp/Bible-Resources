# Historical research — non-operational archive

This directory preserves dated investigations and early pipeline trials for reproducibility. **It is not part of the active production documentation.** Start with [the current process](../docs/PRODUCTION_PIPELINE.md), [general workflows](../docs/workflows/README.md) and [source fidelity rules](../docs/policies/README.md).

- [Cross-cutting pipeline research](pipeline/) — dated normalizer, toolchain and early stage-audit experiments.
- [Early pilots](pilots/) — initial onboarding and experimental source/native investigations.
- [Historical resource inventory](inventory/) — edition snapshots formerly mixed into general architecture.
- [Document relocation ledger](DOCUMENT_RELOCATIONS.json) — original locations and Git blob identities for historical review.

**Edition-specific material lives with the edition:** `sources/cleaned/<type>/<language>/<module-id>/editorial/`. This includes release receipts, source/witness investigations, decisions, reader QA and edition-specific histories. Do not add those reports back into `docs/` or this general historical directory.

The archived records are preserved evidence; their former dates and interim conclusions are not current publication decisions.
