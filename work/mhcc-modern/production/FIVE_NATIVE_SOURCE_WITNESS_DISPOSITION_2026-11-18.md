Immutable 0.1.0 ZIP SHA256: `0faf4376b6b97093ecb94f306886c24d3030ab1f5e194472ad908dd73921f9c0`; original complete native ordered corpus SHA256: `8abd8bedb4eb0ff425999a9435e18d3c302d3a4f47863e3af5b1de36dfd538e6`. These different digital editions have different *compiled raw hash identities*, so each must be authenticated against **its own** exact immutable archive and native corpus; demanding cross-recompiled byte equivalence is not valid. Source preservation of the archived 0.1.0 data is separately attested by [its public release documentation](../../../../docs/releases/MHCC-0.1.0.md).

The new [generic native lexical-witness probe](../../../scripts/commentary_modern_native_witness_probe.py) (manifest [here](NATIVE_FIVE_CHAPTER_ANCHOR_PROBES.json)) validates the full corpus SHA and the original grouped K raw SHA against the corresponding *edition's own* native receipt. It then tests ordered 4–18 word English phrase anchors inside the exact original K raw XML, also searching other K/I bodies **within the same chapter** when a phrase is absent. **No original commentary prose, original native XML, or full authored text is exported.**

**Crucial distinction:** absence of several short exact CCEL phrase sequences in authenticated CrossWire SWORD is strong evidence that **these particular CCEL formulations** are absent. It is **not** exhaustive proof that every word of an authored unit was omitted, that two separately digitized editions have identical authorship, or that release rights for CCEL-specific content have been granted. The final decision needs exact full primary-original versus independently documented source edition clause/paragraph comparison.

3. **No released MHCC 0.1.1 source text, Bible verse, address, authorial paragraph or markup was edited.** Neither BRMHCC 0.1.0 nor the current SWORD catalogue or release metadata was altered.
4. **No compiled modern derivative**, independent editorial signoff, whole-body literal/source-reference proof, reader acceptance, rights determination, merge or release is implied. The PR stays draft, and **0/1,189** modern chapters are independently source-meaning approved.
