# Working and research evidence

New **unpublished** work goes in `work/<type>/<resource-id>/`.
Types: `bibles`, `commentaries`, `dictionaries`, `encyclopedias`,
`other`. Per resource, use `drafts/`, `audits/`, `tests/` only when
necessary. Keep disposable output outside version control.

**Important:** the existing `work/mhcc-modern/` contains long-lived
authored translation manuscripts and source-bound review records from the
published HMCC Modern effort, **not trash or expendable scratch**. Leave it
in place during this first workspace reorganization to preserve workflows,
GitHub permalinks, audit receipts and reproducibility. A future verified
path migration must retain all relevant evidence. The `research/mhc-ccel/`
experiment similarly remains archived at its historical path.

Review [workspace organization and migration gates](../docs/WORKSPACE_LAYOUT.md)
before moving existing evidence. Keep immutable originals in `sources/original`
(only with rights), edited masters in `sources/cleaned`, and SWORD packages
in `modules`.
